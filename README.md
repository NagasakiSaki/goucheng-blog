# 构成 / GOUCHENG · 公开个人博客

公开网站：https://nagasakisaki.github.io/goucheng-blog/

## 发表文章，让所有人看到

1. 打开网站右上角「作者发布」，点击「发表新文章」。
2. 用 `NagasakiSaki` 的 GitHub 账号登录，填写标题与 Markdown 正文。
3. 保留 `article` 标签，提交 Issue 即为公开发表。回到博客点击「刷新文章」读取最新内容。
4. 编辑同一篇 Issue 更新文章，关闭 Issue 则从博客下架。

只有仓库所有者创建、带 `article` 标签且状态为开放的 Issue 会成为博客文章。读者无需账号即可阅读，登录 GitHub 后可在文章对应的 Issue 下公开评论。其他访客提交的 Issue 不会成为作者文章。

顶部 `category` 是分类，`tags` 是逗号分隔的标签，`summary` 是摘要，`art` 可为 order / walk / less / type / paper / unfinished，`pinned: true` 表示置顶。正文放在第二条 `---` 之后。图片可直接拖入 GitHub 编辑框上传。

线上版统一读取 GitHub 文章，打开页面和返回页面时检查更新，也可点击「刷新文章」。GitHub 列表索引及缓存可能有短暂延迟。网络或公共 API 请求受限时，会保留上次成功获取的公开内容并提示失败。

作者资料与站点名称在 main 分支的 `public/site.json`，编辑后刷新博客即可读取。收藏、阅读历史和主题仍保存在个人浏览器，不会上传。页面不含 GitHub 访问令牌。

## 更新网站界面

```sh
npm install
npm test
npm run deploy
```

此命令通过本机 GitHub CLI 获取公开文章快照，构建网站，再推送静态文件到 `gh-pages` 分支。源码位于 main 分支，GitHub Pages 从 gh-pages 分支发布。日常发表或修改文章不需要重新部署。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的地址（默认 http://localhost:5173）。

```sh
npm run build
npm run preview
npm test
```

构建结果在 `dist/`，可部署至静态托管服务。本工作区的 Sites 尚未启用，当前提供本地预览与完整代码。

## 数据边界

这是**本地优先静态应用**，没有服务端和账号体系。文章、留言、收藏、偏好和阅读统计保存在当前浏览器的 localStorage，不能跨设备自动同步。创作中心不是登录保护的管理后台，每个访客只会修改自己浏览器里的内容。

留言和阅读次数明确标注“本地 / 本机”。定时发布在网站打开后按设定时间显示，关闭网站期间没有后台任务。RSS 提供当前文章的 XML 文件快照，不是自动更新的在线订阅接口。账号权限、公开评论、邮件订阅和跨设备同步需要接入服务端。

重要内容修改后，先保存文章，再到「创作中心 → 数据备份」导出 JSON。未提交编辑单独保存在浏览器，**不包含在 JSON 文章备份内**，导出前请先保存成草稿。清除浏览器数据会清除这些内容。

合并导入不覆盖同 ID 的当前文章，不删除当前内容。迁移设备时，可先导出 JSON，在另一设备打开网站后合并导入。

封面支持 5 MB 内 PNG / JPEG / WebP，自动缩至最长边 1200px，压缩为 JPEG。支持最多 500 篇文章、每篇正文 200000 字符、5000 条留言；实际容量受浏览器 localStorage 限制。保存失败会提示，编辑内容保留在页面。

## 快捷键

- `/`：打开搜索。
- `Esc`：关闭弹窗，保留编辑缓冲区。
- `Ctrl / ⌘ + S`：在编辑器保存文章。

## 代码结构

- `src/main.js`：阅读、搜索、主题、路由和状态持久化。
- `src/studio.js`：创作中心、编辑器、设置、回收站和备份。
- `src/model.js`：模型、发布规则、筛选、备份校验及合并。
- `src/posts.js`：首次打开的六篇示例文章和作者资料。
- `src/shell.js`、`src/art.js`：首页和几何海报。
- `src/style.css`、`src/features.css`、`src/responsive.css`：样式和适配。
- `tests/model.test.js`：发布边界、日期筛选、备份与合并测试。

初始化后，以浏览器里的内容为准；修改示例文件不会覆盖已有文章。Google Fonts 可选加载，失败时回退至设备字体。
